## Enums

<Card title="Result[T, E]">
  Either a success value or an error. `?` on a `Result` unwraps `Ok` and returns `Result.Err(e)` from the enclosing function.

  ----

  **Variants:**
  ```zn
  Ok: T,
  Err: E,
  ```

  **Inspection:**
  ```zn
  pub fn is_ok(*const self) bool;
  ```
  ```zn
  pub fn is_err(*const self) bool;
  ```

  **Extraction:**
  ```zn
  pub fn unwrap(self) T;
  ```
  ```zn
  pub fn unwrap_err(self) E;
  ```
  ```zn
  pub fn unwrap_or(self, default: T) T;
  ```
  ```zn
  pub fn unwrap_or_else[F: CallableOnce() T](self, f: F) T;
  ```
  ```zn
  pub fn expect(self, msg: []const char) T;
  ```
  ```zn
  pub fn expect_err(self, msg: []const char) E;
  ```
  ```zn
  pub fn ok(self) Option[T];
  ```
  ```zn
  pub fn err(self) Option[E];
  ```

  **Combinators:**
  ```zn
  pub fn map[U, F: CallableOnce(T) U](self, f: F) Result[U, E];
  ```
  ```zn
  pub fn map_or[U, F: CallableOnce(T) U](self, f: F, default: U) Result[U, E];
  ```
  ```zn
  pub fn map_err[G, F: CallableOnce(E) G](self, f: F) Result[T, G];
  ```
  ```zn
  pub fn and_then[U, F: CallableOnce(T) Result[U, E]](self, f: F) Result[U, E];
  ```
  ```zn
  pub fn inspect[F: CallableOnce(*T) void](self, f: F) Self;
  ```
  ```zn
  pub fn inspect_err[F: CallableOnce(*E) void](self, f: F) Self;
  ```
