## Interfaces

<Card title="Sliceable">
  Produces a slice view over a range of the container.

  ----

  **Generic parameters:**
  ```zn
  [T]
  ```

  **Methods:**
  ```zn
  pub fn slice(*const self, range: Range) []T;
  ```
</Card>

## Structures

<Card title="Range">
  Bounds of a slice or an index range:

  * `lo..hi` gives `{ start: Some, end: Some }`
  * `lo..=hi` gives `{ start: Some, end: Some + 1 }`
  * `lo..` gives `{ start: Some, end: None }`
  * `..hi` gives `{ start: None, end: Some }`
  * `..=hi` gives `{ start: None, end: Some + 1 }`
  * `..` gives `{ start: None, end: None }`

  ----

  **Fields:**
  ```zn
  pub start: Option[usize],
  pub end: Option[usize],
  ```

  ----

  **Methods:**
  ```zn
  pub fn first(*const self) Option[usize];
  ```
  ```zn
  pub fn last(*const self) Option[usize];
  ```

  ----

  **Interfaces:**
  - `core.ops` : `Copy`
  - `core.iter` : `Iterator` (`Item = usize`, yields every index in the range)
</Card>
