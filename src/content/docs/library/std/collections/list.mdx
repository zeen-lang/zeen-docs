`List[T]` is a growable heap buffer. Elements live inline, and the buffer doubles when it runs out of room.

```zn
use std.collections.list;

fn main() {
  let items: List[i32] = List.new();

  items.push(1);
  items.push(2);

  @println("len: {}, first: {}", items.len(), items.first().unwrap());
}
```

## Building from a slice

`List.from` has two overloads. `Copy` elements are copied, `Clone` elements are cloned. A type that is both takes the `Copy` block, which never runs user code:

```zn
use std.collections.list;
use std.string;

fn main() {
  const numbers: [3]i32 = {1, 2, 3};
  const copied: List[i32] = List.from(numbers[..]);

  const words: [2]String = {String.from("a"), String.from("b")};
  const cloned: List[String] = List.from(words[..]);

  @println("{} {}", copied.len(), cloned.len());
}
```

## Iteration

The three directions yield pointers for borrowing and values for consuming:

```zn
use std.collections.list;

fn main() {
  const numbers: [3]i32 = {1, 2, 3};
  let items: List[i32] = List.from(numbers[..]);

  for (item : items.iter()) {
    @println("{}", *item);
  }

  for (item : items.iter_mut()) {
    *item += 10;
  }

  for (item : items.into_iter()) {
    @println("{}", item);
  }
}
```
