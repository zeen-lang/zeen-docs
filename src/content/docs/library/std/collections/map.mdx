`HashMap[K, V]` stores entries in chained buckets over a `List`. The load factor is 0.75 and the bucket count doubles when it is crossed. Keys need `Hash + Eq`.

```zn
use std.collections.map;
use std.string;

fn main() {
  let map: HashMap[String, i32] = HashMap.new();
  const key: String = String.from("a");

  const previous = map.insert(key, 1);

  @println("{}", previous.is_none());

  switch (map.get(&String.from("a"))) {
    .Some(value) => @println("{}", *value),
    .None => @println("nothing"),
  }
}
```

## Lookup and mutation

`get` returns a borrow into the bucket, never a copy. `insert` returns the value it displaced:

```zn
use std.collections.map;
use std.string;

fn main() {
  let counts: HashMap[String, i32] = HashMap.new();
  const previous = counts.insert(String.from("zeen"), 1);

  @println("{}", previous.is_none());

  const key: String = String.from("zeen");

  switch (counts.get_mut(&key)) {
    .Some(value) => {
      *value = *value + 1;
    },
    .None => {},
  }

  @println("{}", *counts.get(&key).unwrap());
}
```

`remove` hands back the value, `remove_entry` hands back the whole entry so the key leaves with it.
