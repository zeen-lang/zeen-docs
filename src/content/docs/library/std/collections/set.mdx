`HashSet[T]` is a chained hash table of unique values. The load factor is 0.75 and the bucket count doubles when it is crossed. Elements need `Hash + Eq`.

```zn
use std.collections.set;

fn main() {
  let tags: HashSet[i32] = HashSet.new();

  @println("{}", tags.insert(1));
  @println("{}", tags.insert(1));
  @println("{}", tags.insert(2));

  @println("len: {}, has 2: {}", tags.len(), tags.contains(&2));
}
```

## Results

`insert` returns `true` when the value was new, `remove` returns `true` when it was present:

```zn
use std.collections.set;
use std.string;

fn main() {
  let names: HashSet[String] = HashSet.new();

  @println("{}", names.insert(String.from("zeen")));
  @println("{}", names.insert(String.from("zeen")));

  const key: String = String.from("zeen");

  @println("{} {}", names.contains(&key), names.remove(&key));
}
```
