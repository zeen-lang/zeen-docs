> **Usage Example**
> ```zn
> use std.env;
>
> fn main() {
>   if (Env.set_var("DEMO", "1").is_ok()) {
>     @println("DEMO={}", Env.var("DEMO").unwrap());
>   };
>
>   @println("cwd: {}", Env.current_dir().unwrap());
> }
> ```
