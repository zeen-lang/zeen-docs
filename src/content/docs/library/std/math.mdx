`std.math` holds the numeric constants, a `Math` namespace of static helpers, the `Float` interface that `f32` and `f64` implement, and the raw declarations from `std.c.math`. The C declarations are not re-exported, so import them with `use std.c.math;`. Every double declaration has a single precision twin with an `f` suffix.

```zn
use std.math;

fn main() {
  const radius = 2.0;
  const area = PI * Math.pow(radius, 2.0);

  @println("{:.2} {:.2}", area, Math.sqrt(area));
  @println("{} {} {}", Math.min(3, 5), Math.gcd(12, 18), (-2.0).abs());
}
```

## Structures

<Card title="Math[T]">
  Static helpers for `Ord` types, integers and floats. Call them on the struct itself, as in `Math.min(a, b)`.

  ----

  **Ordering (`T: Ord`):**
  ```zn
  pub fn min(a: T, b: T) T;
  ```
  ```zn
  pub fn max(a: T, b: T) T;
  ```
  ```zn
  pub fn clamp(value: T, lo: T, hi: T) T;
  ```

  **Signed (`T: Ord + Neg`):**
  ```zn
  pub fn abs(x: T) T;
  ```

  **Integers:**
  `pow`, `gcd`, `lcm` and `signum` exist for `i32`, `i64`, `u32` and `u64`. Each version takes and returns its own type:
  ```zn
  pub fn pow(base: i32, exp: u32) i32;
  ```
  ```zn
  pub fn gcd(a: i32, b: i32) i32;
  ```
  ```zn
  pub fn lcm(a: i32, b: i32) i32;
  ```
  ```zn
  pub fn signum(x: i32) i32;
  ```
  `gcd` returns a non-negative value, `lcm` returns zero when either side is zero, and `signum` gives `-1`, `0` or `1`. Unsigned `signum` gives `0` or `1`.

  **Floats:**
  Every `Float` method also exists here for `f64` and `f32`, with the value as the first argument:
  ```zn
  pub fn sqrt(x: f64) f64;
  ```
  ```zn
  pub fn pow(x: f64, y: f64) f64;
  ```
  ```zn
  pub fn atan2(y: f64, x: f64) f64;
  ```
  ```zn
  pub fn lerp(a: f64, b: f64, t: f64) f64;
  ```
  Each call has an `f32` twin that takes and returns `f32`. `Math.sqrt(x)` and `x.sqrt()` compute the same value.
</Card>
