title: Primitives
description: Builtin methods for integers, floats, char and bool, declared in implement builtin blocks.
---

import { Badge, Card } from '@astrojs/starlight/components';

**Module:** <Badge text="std.primitives" variant="note" size="medium" /> <br/>
**Source:** [std/primitives](https://github.com/zeen-lang/zeen/tree/main/lib/std/src/primitives) <br/>

`std.primitives` is a folder with one module per builtin type. Every module declares its methods in an `implement builtin` block.

The resolver injects `use std.primitives.<type>` into every module of the program, so the methods work without imports. Core modules and the primitive files themselves are skipped. Without a std root the methods are absent.
