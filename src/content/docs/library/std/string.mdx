`String` owns a heap buffer of UTF-8 bytes. It grows geometrically, implements `StrWriter` so `@format` and `Display` can write into it, and exposes both byte and rune access.

```zn
use std.string;

fn main() {
  let text: String = String.from("hello");

  text.push_str(" world");

  @println("{}", text);
}
```

## Bytes and runes

`len` counts bytes, `rune_count` counts code points. Methods with a `char` argument work on single bytes, methods with a `Rune` argument decode UTF-8:

```zn
use std.string;

fn main() {
  const text: String = String.from("héllo");

  @println("{} bytes, {} runes", text.len(), text.rune_count());

  const accented = Rune.from_u32(0xE9).unwrap();
  const found = text.find_rune(accented).unwrap();

  @println("byte {}, rune {}", found, text.nth_rune(1).unwrap().to_u32());
}
```

`reverse` moves whole runes, so multi byte sequences stay intact. `truncate` cuts at a byte offset and can split a rune, use `pop_rune` when you need clean UTF-8.

## Building from runes

```zn
use std.string;

fn main() {
  let out: String = String.new();

  out.push_rune(Rune.from_ascii('a').unwrap());
  out.push_rune(Rune.from_u32(0x1F600).unwrap());

  @println("{} {}", out.rune_count(), out);

  switch (out.pop_rune()) {
    .Some(rune) => @println("{:?}", rune),
    .None => @println("empty"),
  }
}
```

## Parsing

Each parser is strict and returns `None` on garbage or overflow:

```zn
use std.string;

fn main() {
  const good: String = String.from("42");
  const bad: String = String.from("4x");

  switch (good.parse_i32()) {
    .Some(value) => @println("{}", value),
    .None => @println("garbage"),
  }

  @println("{}", bad.parse_i32().is_none());
}
```
