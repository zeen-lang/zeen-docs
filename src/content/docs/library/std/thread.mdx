> **Usage Example**
> ```zn
> use std.thread;
>
> fn main() {
>   const handle = Thread.spawn(|| -> i32 {
>     return 42;
>   });
>
>   @println("{}", handle.join());
> }
> ```

The closure runs on a new OS thread, `join` waits for it and returns the closure result. Shared state goes through `Arc` with `Mutex` from [Sync](/library/std/sync/), which this module re-exports.
