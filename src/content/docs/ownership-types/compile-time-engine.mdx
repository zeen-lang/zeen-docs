title: Compile Time Engine
description: Compile time constants, functions, blocks, structs, type captures and reflection.
---

`comptime` evaluates code while the program compiles and substitutes the result into the program. Compile time values take no runtime storage.

## Constants

`comptime NAME = expr;` builds a constant with no type annotation. Every use site receives the value itself:

```zn
comptime N = 16;
comptime SquaredN = N * N;

fn main() {
  @println("{} {}", N, SquaredN);
}
```

A name works as a normal expression. A splice `$(NAME)` writes the value as text, which is what string literals and captured syntax need:

```zn
comptime N = 16;

fn main() {
  @println("$(N) squared is $(N * N)");
}
```

A `pub comptime` name is visible through `use` in another module.

## Functions

A compile time function takes comptime parameters and returns a comptime value. Recursion works, and a call may appear in a type position:

```zn
comptime fn fact(n: comptime_int) comptime_int {
  if (n <= 1) {
    return 1;
  };

  return n * fact(n - 1);
}

comptime fn double(x: comptime_int) comptime_int {
  x * 2
}

fn main() {
  const values: [double(2)]i32 = {1, 2, 3, 4};

  @println("{} {}", fact(5), values[3]);
}
```

`[double(2)]i32` becomes `[4]i32` during compilation.

## Blocks

`comptime { ... }` works at three levels. At declaration level it runs once and may emit declarations. At statement level it runs inside a runtime function. At expression level it yields the value of its tail expression:

```zn
comptime {
  @println("declaration level");
}

fn main() {
  comptime {
    @println("statement level");
  }

  const size = comptime { 4 * 8 };

  @println("{}", size);
}
```

A block produces output during compilation, prefixed with the file and line.

## Structs

`comptime struct` holds comptime fields. The value is `Copy`, accepts the usual `self` receivers and stays out of the runtime program:

```zn
comptime struct Point {
  x: comptime_int,
  y: comptime_int,
}

comptime Origin = Point { .x = 0, .y = 0 };
comptime Corner = Point { .x = 3, .y = 4 };

fn main() {
  @println("origin is $(Origin.x), $(Origin.y)");
  @println("corner is $(Corner.x), $(Corner.y)");
}
```

Core uses the same feature for reflection records in [core.reflection](/library/core/reflection/).

## Captured types and declarations

| Macro | Result |
|---|---|
| `@zeen_type(T)` | a type as a `zeen_type` value |
| `@zeen_expr(expr)` | an expression as a `zeen_expr` value |
| `@zeen_decl(decl)` | a declaration as a `zeen_decl` value |
| `@emit(decl)` | writes a captured declaration into the program |
| `@fresh_name(prefix)` | a unique name `prefix_N` |

A captured type acts like an alias, and `$(...)` fills the holes:

```zn
comptime fn array_type(n: comptime_int) zeen_type {
  return @zeen_type([$(n)]i32);
}

alias Buffer = array_type(3);

fn main() {
  const values: Buffer = {1, 2, 3};

  @println("{}", values[1]);
}
```

A captured expression splices back into runtime code:

```zn
comptime fn twice(n: comptime_int) zeen_expr {
  return @zeen_expr($(n) + $(n));
}

comptime Captured = @zeen_expr(1 + 2);

fn main() {
  const sum = $(Captured);
  const four = $(twice(2));

  @println("{} {}", sum, four);
}
```

A captured declaration goes out through `@emit`, and `@fresh_name` mints names for a loop:

```zn
comptime fn named_struct(name: comptime_str) zeen_decl {
  @zeen_decl(
    pub struct $(name) {
      pub value: i32
    }
  );
}

comptime {
  @emit(named_struct("Alpha"));

  for (i : 0..2) {
    const name = @fresh_name("Item");

    @emit(@zeen_decl(
      pub struct $(name) {
        pub index: i32
      }
    ));
  }
}

fn main() {
  const alpha = Alpha { .value = 10 };
  const second = Item_1 { .index = 2 };

  @println("{} {}", alpha.value, second.index);
}
```

`@emit` adds declarations next to the block that calls it, so the generated `Alpha` and `Item_N` are ordinary structs in that module.

## Reflection

| Macro | Result |
|---|---|
| `@fields(T)` | array of `Field` records |
| `@variants(T)` | array of `Variant` records |
| `@typeInfo(T)` | `struct` or `enum` |
| `@hasField(T, name)` | `bool` |
| `@fieldType(T, name)` | the field type |

```zn
struct Point {
  pub x: i32,
  pub y: i64,
}

enum Shape {
  empty,
  circle: f64,
}

comptime {
  @println("{}", @typeInfo(Point));
  @println("{} {}", @hasField(Point, "x"), @fieldType(Point, "y"));

  for (field : @fields(Point)) {
    @println("{}: {}", field.name, field.ty);
  }

  for (variant : @variants(Shape)) {
    @println("{} {}", variant.name, variant.payload);
  }
}

fn main() {
}
```

A `Field` record holds `index`, `name` and `ty`. A `Variant` record holds `index`, `name` and `payload`, which is `none` or `value`. Reflection macros work only inside comptime. `@variantNames` and `@variantCount` are runtime macros, covered on [Builtin Macros](/language-basics/macros-builtin/).

## Formatting and layout

`@print`, `@println`, `@format`, `@dbg` and `@panic` take the same format strings as at runtime. `@sizeof(T)` and `@alignof(T)` return `comptime_int` here:

```zn
comptime Size = @sizeof(i64);
comptime Align = @alignof(f64);

fn main() {
  @println("{} {}", Size, Align);
}
```

## Allowed types

A comptime value is one of:

- `comptime_int`, `comptime_float`, `comptime_bool`, `comptime_char`, `comptime_str`
- `zeen_type`, `zeen_expr`, `zeen_decl`
- a comptime struct
- an array of the above
- `void`, as a return type

Runtime types such as `i32`, `f64` or `String` are rejected in comptime signatures and local annotations (`zeen::comptime::runtime_type`). `@uninit` reports `zeen::comptime::runtime_only`, and `@void()` is gone entirely. Only the empty `.{ }` form is evaluated at comptime.

## Limits

The interpreter has a step budget and a recursion depth limit. Exceeding either one is a compile error with the code `zeen::comptime::limit_exceeded`.
