---
title: Linking
description: Linker selection per target, overrides and output suffixes.
---

The object file from codegen links into a binary with a toolchain picked by the target.

## Selection
| Target | Toolchain |
|---|---|
| gnu family | gcc alias for the triple, such as `x86_64-linux-gnu-gcc` |
| host equals target | native `cc` or `gcc` |
| anything else | `clang -target <triple>` |
| Windows MSVC | `link.exe`, only on Windows |
| Wasm | `wasm-ld --allow-undefined` |

The linker probes the gcc family alias first, then falls back to `clang`. Wasm turns missing symbols into imports because of `--allow-undefined`.

## Overrides
| Flag | Effect |
|------|--------|
| `--linker-path <program>` | override detected linker |
| `--link <LIB>` | append `-l<LIB>` (gcc, clang) or `<LIB>.lib` (MSVC) |
| `--link-dir <PATH>` | append `-L<PATH>` (gcc, clang) or `/LIBPATH:<PATH>` (MSVC) |
| `extern link "file.c"` | append after object, skipped with warning on object-only toolchains |

Output suffix follows the target: `.exe` on Windows, `.wasm` on Wasm.
